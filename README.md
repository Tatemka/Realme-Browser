# Realme Browser

Простой и лёгкий браузер для Android в стиле Realme UI.

## ✨ Особенности

- Чёрно-жёлтая тема оформления
- Адресная строка для ввода URL
- Кнопки навигации: Назад, Вперёд, Обновить
- Быстрый и минималистичный интерфейс

## 📱 Системные требования

- Android 5.0 (Lollipop) или выше
- 10 МБ свободного места

## 📦 Установка

1. Скачайте APK-файл из раздела **Releases**.
2. Откройте файл на телефоне и разрешите установку из неизвестных источников.
3. Нажмите "Установить".

## 🛠️ Сборка из исходников

Проект создан в MIT App Inventor 2. Чтобы внести изменения:

1. Импортируйте файл проекта (.aia) в MIT App Inventor.
2. Внесите правки в интерфейсе и блоках.
3. Нажмите "Построить" → "Android App (.apk)" для создания нового APK.
